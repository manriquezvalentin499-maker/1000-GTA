# Servidor de GTA 1000 en Render

1. En la página principal de tu repositorio GitHub, selecciona **Add file → Upload files**.
2. Selecciona los siete archivos extraídos del ZIP, incluido **Dockerfile**, y pulsa **Commit changes**.
3. En Render, selecciona **New → Blueprint** y conecta ese repositorio.
4. Cuando el servicio esté activo, abre GTA 1000 y pega `wss://TU-SERVICIO.onrender.com` en **Multijugador por Internet**.
